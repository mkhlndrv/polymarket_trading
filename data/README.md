# data/

Everything here is regenerated by code and git-ignored. Sizes from the 2026-09-30 build:

| file | built by | contents | size |
|---|---|---|---|
| `research.duckdb` | `inventory`, `trades`, `truth`, `labels` | markets, rules_history, trades, observations, truth, daily_truth | 1.9 GB |
| `prices.duckdb` | `prices` | prices_history: 1-minute CLOB price points for 118,924 bucket markets | 775 MB |
| `forecasts.duckdb` | `forecasts` | forecasts, forecast_runs: 2 m temperature per station, model, run and step with publication times | 136 MB |
| `trades.parquet` | `trades` | 27.9M on-chain fills for the inventory markets (from the SII-WANGZJ/Polymarket_data dataset) | 1.1 GB |
| `raw/*.jsonl` | `inventory` | Gamma event dumps (one per run) | ~200 MB |
| `iem/*.csv` | `truth` | METAR archives per station and year from the Iowa Environmental Mesonet | ~400 MB |
| `collector/`, `paper/` | `collector`, `paper` | live snapshots (Parquet) and paper-trading state | grows |

Sources, licences and quirks are in `docs/PLAN.md` section 5 and 12. `make data` rebuilds all of it (hours; the trades stream alone is 36 GB).
